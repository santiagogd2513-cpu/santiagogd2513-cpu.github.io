📲 Cómo instalar un APK

  1. Toca Descargar en la app que quieras.
  2. Abre el archivo desde las notificaciones o desde tu gestor de archivos.
  3. Si Android pregunta, permite instalar apps de esta fuente (solo la primera vez).
  4. Las apps se actualizan instalando el APK nuevo encima: no pierdes nada.

⛏️ Cómo instalar los mods (Forge)

  1. Necesitas Minecraft Java Edition. En tu launcher, juega una vez la versión 1.20.1 para que se descargue.
  2. Atajo: muchos launchers (como Prism Launcher o el de CurseForge) instalan Forge solos: crea una instancia 1.20.1 con Forge y salta al paso 6.
  3. Descarga el instalador de Forge 1.20.1 (versión 47) desde files.minecraftforge.net: toca Installer. La página muestra un anuncio: espera unos segundos y toca Skip arriba a la derecha.
  4. Abre el instalador, elige Install client y toca OK.
  5. En tu launcher aparece el perfil forge: ábrelo una vez y cierra el juego (así se crea la carpeta mods).
  6. Descarga el .jar del mod aquí arriba y cópialo en la carpeta mods:
    Windows: tecla Windows + R → escribe %appdata%\.minecraft\mods → Enter.
    Linux: ~/.minecraft/mods · Mac: ~/Library/Application Support/minecraft/mods
  7. Abre Minecraft con el perfil forge. En el menú, Mods muestra el mod instalado. ¡A jugar!
  8. En el celular: con un launcher de Java como PojavLauncher, instala Forge 1.20.1 desde el launcher y copia el .jar en su carpeta mods.

🧱 Cómo instalar addons y paquetes de recursos

  1. Descarga el addon (.mcaddon) o el paquete (.mcpack).
  2. Tócalo: Minecraft se abre solo y dice «Importación correcta».
  3. Crea o edita un mundo y entra en Paquetes de comportamiento o Paquetes de recursos.
  4. Busca el que importaste y toca Activar.
  5. Si el addon lo pide, activa los Experimentos en la configuración del mundo.
  6. Entra al mundo y disfruta.
  7. Y cuando salgan nuestros mods para Bedrock, los instalas igualito. 😎
